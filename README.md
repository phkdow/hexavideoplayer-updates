# Hexa Video Player（更新の配布用）

6画面同時再生の動画プレーヤー「Hexa Video Player」の、自動アップデートを配布するためのリポジトリです。ソースコードは置いていません。

## 中身
- `latest.json` … 最新版の番号・ダウンロード先・sha256・変更点。アプリが最初に読むファイルです。
- `updates/HexaVideoPlayer-<版>.hexavideoplayer-update` … 署名付きの更新ファイル（最新の1つだけ）。

## 自動アップデートのしくみ
- アプリは起動の12秒後と24時間ごとに `latest.json` を確認します。リボンの「ヘルプ」→「更新を確認」でもすぐ確認できます。
- 新しい版があると「今すぐ更新／あとで／このバージョンは飛ばす」と聞きます。「今すぐ更新」を選ぶと、アプリをいったん閉じて中身を入れ替え、自動で起動し直します。
- 新しい版が正しく起動しなかったときは、自動で元の版に戻し、次の起動で知らせます。
- 更新ファイルは ed25519 の電子署名つきです。署名が合わないもの・壊れたものは使いません。
- 更新ファイル（`.hexavideoplayer-update`）をダブルクリックしても、手動で更新できます。
